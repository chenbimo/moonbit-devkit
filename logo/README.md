# 模块 logo 生成器

给工作区里的每个 MoonBit 模块出一个统一的 logo:长方形圆角底 + 双色名称,字形转成 path 内嵌。

## 一条命令

```bash
cd moonbit/scripts/logo
bun install                                  # 首次
bun logo.mjs --name BM2 --out ../../bm2/docs/public/logo.svg
```

换模块只改 `--name`(和输出路径)。名称前两个字符用第一色,其余用第二色。

## 为什么字形要转 path

SVG 里写 `<text>` 会由渲染器按本机字体排版:同一份文件在浏览器、resvg、rsvg 里字宽与基线都不同,实测同一张 logo 的留白差到 8px。转成 `<path>` 之后几何在这里算死,谁渲染都一样。

## 排版由墨迹决定,不是由字宽

块宽 = 墨迹宽 + 2×左右边距,块高 = 墨迹高 + 2×上下边距。用字宽会把字体自带的侧边距也算进去,留白会比设定的多几像素。

默认左右 22、上下 24 —— 上下略大于左右,视觉上更透气。

## 参数

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `--name` | 必填 | 显示名,建议全大写 |
| `--out` | 必填 | 输出 SVG 路径,同名 PNG 落在同目录 |
| `--split` | `2` | 前几个字符用第一色 |
| `--bg` | `#0284c7` | 底色 |
| `--one` | `#ffffff` | 第一色 |
| `--two` | `#ffd60a` | 第二色 |
| `--pad-x` | `22` | 左右内边距 |
| `--pad-y` | `24` | 上下内边距 |
| `--radius` | `16` | 圆角 |
| `--size` | `45` | 字号 |
| `--raster` | — | 额外导出 PNG 高度,逗号分隔,如 `32,180` |

## 位图

需要 PNG(favicon、app icon)时加 `--raster 32,180`,内部用 `@resvg/resvg-js` 直接转,不依赖系统图像工具。

位图的其它处理(压缩、缩放、转格式)用 `Bun.Image`,见工作区规矩。
